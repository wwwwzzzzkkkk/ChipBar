# ChipBar 图标

`AppIcon.png` 是带透明外边距的图标原稿，由内置 imagegen 生成；深色芯片、青蓝色闪电和波形对应芯片功率监控。原稿保留在仓库，构建使用 macOS 自带 `sips` 和 `iconutil` 自动导出 16–1024 px 的普通与 Retina 尺寸并生成 `AppIcon.icns`。

应用图标会显示在 Finder、应用程序目录和弹窗标题中。菜单栏保留适合系统主题的单色闪电与实时功率文字。
